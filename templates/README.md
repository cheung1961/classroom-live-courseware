# 课堂互动课件（学生端 + 教师实时大屏）

学生用浏览器作答，教师机大屏**实时**汇总全班正确率与开放作答。零依赖，仅需 Node.js。

## 上课怎么用（三步）
1. 教师机装好 Node.js（≥14），进入本文件夹，执行 `npm start`（或 `node server.js`）。
2. 教师端浏览器打开 `http://localhost:3000/teacher` 投屏；学生端打开 `http://localhost:3000/`。
3. 学生用**教师机局域网 IP** 访问（如 `http://192.168.1.10:3000/`），输姓名即可作答。

## 换题（唯一需要改的地方）
只编辑 `public/content.js` 里的 `title` 与 `questions` 数组。支持的题型：
- `choice` 单选、`judge` 判断、`calc` 填空计算、`drag` 拖拽分类、`open` 开放作答。
- 详细字段见文件内注释，新增/修改题目无需改动其他文件。

## 重要说明
- **GitHub Pages 跑不了实时汇总**：Pages 只托管静态文件，不能跑 Node 服务。GitHub 仅作代码备份；课堂实时汇总必须本地跑 `node server.js`。
- 端口：`PORT` 环境变量可改，默认 3000。重启服务会清空已提交数据（内存态，课堂期间有效）。
- 局域网：学生用教师机 `ipconfig` 查到的局域网 IP 访问，不是 localhost。
- 身份：学生端首次打开要求输入姓名（存浏览器本地）；同一浏览器重复提交会覆盖该学生记录。
